# 制作记录

记录日期：2026-10-25。项目仍在制作，未验收的部分不作为已交付能力。

## 目标与顺序

先让 Windows on ARM 上的 AIRI 使用本地 Qwen3.5 9B、中文识别、中文合成及屏幕摘要，再制作菲欧妮·蕾法爱菈角色卡和 Live2D。日常运行不依赖互联网；下载、源码更新和发布 GitHub 是单独的联网操作。

## 已完成的环境工作

- 复用已有 Qwen3.5-9B-Q4_K_M GGUF 和原生 ARM64 CUDA llama.cpp，没有复制一份 9B 权重。另加匹配的视觉投影模型，为 AIRI 开独立回环服务，保留原有工作台服务。
- 复用已有 SenseVoice int8、FFmpeg、创作环境 ARM64 Python；只增加缺失的 MeloTTS 中文/英文中性女声及独立音频服务依赖，不修改共用 Python 环境。
- AIRI 的桌面依赖含仅提供 Windows x64 二进制的拖动插件，故使用 x64 Node/Electron 仿真；推理和语音仍用 ARM64 后端。
- 在 AIRI 编译输出之外维护离线启动模板；配置及源代码更新分开，启动不拉取代码。更新前备份，Git 工作区有修改则停止自动合并。
- 限制 AIRI 自身网络到本机回环地址；语音活动检测所需模型和准确版本的 ONNX Runtime 从本地服务加载。修复了 Transformers 3.8.1 动态加载器原先尝试访问 jsDelivr 的问题，没有用不匹配的新版 WASM 代替。
- 屏幕摘要在内存处理，送本机视觉模型；只保留最新摘要作为角色上下文，不保存屏幕截图到制作记录。

## 已完成的验证

- 本地视觉模型辨认合成测试图中的文字、颜色和形状。
- 中文 WebM 识别、WAV/MP3 合成、TTS→ASR 回转及重复启动通过。
- AIRI 启动迁移配置成功；VAD 本地资源加载后，运行健康检查未报告 VAD/WASM/ASR 错误。
- 屏幕上下文已连续发布成功。实际应用聊天→合成播放链路和整套停止/重启仍在验收中。

## 角色资料与表情研究

只将官方角色页、代理人档案、版本公告及官方视频作为设定证据。事实、视觉观察、原创角色扮演写法分开标注；不补造尚未核实的年龄、身高、剧情或台词。

目前没有找到可确认授权、可直接导入的完整菲欧妮 Live2D 运行包。普通立绘、壁纸、3D 模型或 LoRA 不记作已有 Live2D。

官方视频文件下载受到服务器限制时，没有绕过限制。公开播放器的缩略故事板可辅助观察表情；其名义采样时间有约 ±2 秒不确定性，不称为精确视频帧。

表情选择优先结合她疲乏、随性、会自嘲而工作时可靠的性格。具体名称、强度和口眼组合以可核对的官方镜头为依据，不用统一笑脸套一组情绪名称。

## Live2D 工具审查

审查后采用 [Ludentes/py-moc3](https://github.com/Ludentes/py-moc3) 的 MIT 许可序列化器，固定提交 `2fb112e11a2d495557cfd09fbea72015cbfd47c5`。未采用另一个包装仓库中没有统一许可的角色案例或工作流。

原 CLI 在测试模型上有网格计数误报及不完整 round-trip 问题，因此编写了独立几何构建与验证代码。测试 MOC3 被 AIRI 已安装的 Live2D Core 接受；左右眨眼和张嘴各自改变对应网格，27 种组合坐标正常。这只证明技术路径，尚不代表角色美术或运行模型已完成。

Live2D Core 不随本仓库重新分发；最终运行仍使用目标应用合法取得的 Core，并遵守其许可。
