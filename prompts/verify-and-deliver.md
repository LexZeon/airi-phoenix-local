# Verification and handoff prompt pack

Execute the builder's inspect/build/validate stages. Use a legally obtained existing Core via an explicit local path. A missing Core is a concrete unperformed check, not a passed test.

Verify:

1. MOC3 is accepted by the target Core and produces a model with finite mesh coordinates.
2. Texture indices, vertex/index ranges and referenced files are valid.
3. Each eye can blink independently; closed-eye layers actually replace open eyes.
4. Mouth-open changes independently from the expression mouth line.
5. Head/body/breath parameters change the intended geometry without broken seams.
6. Named expressions have observable, distinct states and return to neutral.
7. The target application can import the package and render it with speech/lip movement.

Prefer a focused contact sheet and a short motion preview for visual review. Capture only the model and synthetic test content; avoid private desktop screenshots in public reports.

Handoff files: project JSON, relative source assets, exact generation prompts, source/license index, final model and export package, actual validation report, and a short statement of limitations. An agent taking over should be able to reproduce the build from these files.

If the target app is AIRI, preserve existing cards and sessions, import as a new character, select the requested local providers, and test with a synthetic short message. A local test passing does not authorize publishing another user's work.
