# 云端 Key 与本机 token 的验证边界

云端 API Key 和9949的本机 bearer token是两种凭证，各自校验。云Key的本地语法检查接受长度16–512的英文字母、数字、下划线、连字符和点号；存储、DPAPI解密后读取与上游请求构造使用相同字符集。不要附加 `Bearer ` 前缀，也不接受内部空格、CR/LF、非ASCII、斜线或冒号。

点号可以出现在合法的工作空间Key中；把云Key误限为原先仅字母数字/下划线/连字符，会在发出网络请求前就拒绝它。这是本地输入兼容性修复。接受一种语法不证明云端鉴权、地域、业务空间或模型权限正确，也不应据此公开真实Key的内容、前缀、业务空间Host或ID。

本机adapter的token仍由程序单独生成，沿用原先43字符的base64url校验；没有因支持云Key点号而放宽。AIRI provider只保存此本机token，不保存云Key。

`python verify_key_formats.py`使用明确的合成值，在临时目录运行真实当前用户DPAPI与请求对象构造。47项检查覆盖原格式、含点号格式、长度边界、加密落盘、公开字段脱敏与非法输入拒绝。两个socket连接入口被禁止，脚本不读取真实private目录、不发云请求、不输出Key，退出后确认临时目录删除。见[匿名结果](verification-key-formats.json)。
